--- 6. Known limitation of this script on 25.12/apk devices (documented, not patched) ---
A1/A2 probe `opkg list-installed` and `/var/opkg-lists/`. On an apk-only box there is no opkg
binary, so A1 reports "absent from opkg list-installed" even though the package IS installed —
a FALSE RED. That is correct for the FE2b target (GL-MT6000 = OpenWrt 24.10.2 / opkg,
corroborated independently in REPORT-fe2b-feed-mt6000.md §2: `which opkg apk` -> /bin/opkg,
opkg version 38eccbb1...), but it means the gate is device-version-specific. It was NOT
patched here: altering the assertions after the baseline was captured would invalidate the
baseline the RED set depends on. If FE2b ever moves to 25.12/apk, A1/A2 need an apk branch
(`apk info -e`, `apk list -I`, `o:` field) added as a new commit, with the baseline re-taken.
